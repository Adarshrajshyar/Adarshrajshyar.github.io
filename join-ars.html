JOINING PROCESS

आवेदन के बाद क्या होगा?

1️⃣

Apply

Join ARS form भरकर application submit करें।

2️⃣

Application ID

Submit होने के बाद unique Application ID मिलेगा।

3️⃣

Review

Authorized ARS team application को review करेगी।

4️⃣

Decision

Application approve या reject की जाएगी।

5️⃣

Certificate

Approval के बाद applicable joining certificate generate होगा।

6️⃣

Notification

Student/member को dashboard और configured email notification मिलेगा।

APPLICATION STATUS
