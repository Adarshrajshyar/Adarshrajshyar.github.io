# Two separate ARS book projects

1. `ARS_BOOK_MANUSCRIPT.md` — the literary ARS Book (shayari, stories, poetry and reflections).
2. `SJR_ARS_ENTRANCE_PREP_MANUSCRIPT.md` — the separate SJR–ARS entrance preparation book for Sainik School, JNV/Navodaya and RMS.

They are separate files, chapters and website pages so each can be reviewed and published independently. The content in these files is a starter manuscript, not a finished full-length book.
